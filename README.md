# Cinnamatica

Cinnamatica adds schematic guides and building tools to Minecraft Bedrock through the Cinnabar client. Import Java schematics and Bedrock structures, preview the blocks in your world, and build by hand or with Fast Place.

| Platform | Where to start |
| --- | --- |
| Windows | [Installer and portable ZIP](https://github.com/Ahwfr/cinnamatica/releases) · [Build from source](builder/windows/README.md) |
| Linux | [Build from source](builder/linux/README.md) with ThsSilentKnight’s launcher and schematic picker |
| iOS | [Port status and platform files](builder/ios/README.md) |
| Android | [Port status and platform files](builder/android/README.md) |

Press **M** in-game to import or load a schematic. The guide shows missing and incorrect blocks, materials, and layers. **V2 Strict** checks placement state and can place compatible blocks directly into air. **Hold to Place** repeats while you hold the use control. **Paste build** is available in Creative with operator permissions.

See the [Cinnamatica guide](builder/README.md), [release notes](builder/RELEASE-NOTES.md), and [contributing instructions](CONTRIBUTING.md). Shared client and schematic code lives in [app](app), [crates](crates), [core](core), and [builder/schematica](builder/schematica).
