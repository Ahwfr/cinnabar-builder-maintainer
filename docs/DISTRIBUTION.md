# Distribution review

The inherited [PolyForm Noncommercial license](../LICENSE) governs the Cinnabar
checkout. Its noncommercial restriction means this project is source-available
under the inherited terms. It does not meet the [Open Source Definition](https://opensource.org/osd).
The [Schematica MIT notice](../builder/schematica/SCHEMATICA-LICENSE.txt)
applies to the referenced Schematica material. Preserve it alongside the root
license, [third-party notices](../THIRD_PARTY_NOTICES.md) and asset notices.

Before public publication, review the reachable commit history and tracked
assets, verify the relevant third-party terms and review the exact release ZIP.
The runtime prepares official Minecraft content locally. Exclude downloaded
resource packs, server binaries, user profiles, credentials, saved worlds,
schematic libraries and compiler caches from any distribution.

The new maintainer repository is private. Public distribution still requires the
owner's approval and completion of the asset and dependency review. The audit
has identified the applicable notices and build pins but has not cleared the
complete history and release payload for redistribution.
